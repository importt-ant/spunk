# Accessors

Accessors are runtime boto3 helpers that let your application code interact
with the AWS resources that were provisioned by spunk.  They are referenced by
the generated SDK package produced by `spunk gen`.

::: spunk.accessors.aws.dynamodb_table.DynamoDBTable

::: spunk.accessors.aws.s3_bucket.S3Bucket
